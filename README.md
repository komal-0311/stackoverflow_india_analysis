# Stack Overflow India Developer Survey Analysis 2024

## About This Project
This project analyzes the Stack Overflow 2024 Developer Survey 
to uncover what skills, experience, and work style help Indian 
developers earn higher salaries. Instead of global trends, this 
focuses specifically on Indian developers — making it directly 
useful for anyone building a tech career in India.

## Dataset
- Source: Stack Overflow Annual Developer Survey 2024
- Platform: Kaggle
- Total Responses: 65,437
- Indian Developers: 4,231
- Full-time Employed Indians with Salary: 809

## What I Analyzed
1. Which programming languages do highest paid Indian developers use?
2. Does work experience actually increase salary in India?
3. Does education level affect salary in India?
4. Remote vs Hybrid vs Office — who earns more?
5. Which developer role pays the most in India?

## Key Findings
- Hybrid workers earn ₹24.57L vs ₹14.64L for office workers
- Niche languages like Groovy and Scala pay more than Python and JavaScript
- Master's degree holders earn ₹22.28L vs ₹17.49L without degree
- Data Scientist role earns ₹29.45L on average in India
- Salary grows from ₹7L at 0 years to ₹57L at 20 years experience
